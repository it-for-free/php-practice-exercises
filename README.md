# Практические уроки по PHP

Раздел на сайте: https://fkn.ktu10.com/?q=node/17702

В данном репоизитории будут примеры кода, используемые в уроках

## Структура

* `lessons-v1/` - docker-окружение для уроков (nginx + php-fpm + xdebug),
  примеры лежат в `lessons-v1/lessons/`. Запуск - `make docker.start.all`
  из `lessons-v1/` (подробности - `make about`).

Одному уроку на сайте будет соответствовать одна поддиректория в разделе уроков.

После запуска контейнеров:
* главная страница со списком уроков: http://localhost:19791/
* урок открывается по адресу http://localhost:19791/lessons/<имя-папки>/
  (например, http://localhost:19791/lessons/lesson01-html-date/)
* служебные файлы репозитория (docker/, Makefile, .md в корне) по URL
  не отдаются - для них настроен 404 в nginx.
